# Kingdom Come: Together on Cairn

A fork of [DeepFriedDepp/KingdomCome-Together](https://github.com/DeepFriedDepp/KingdomCome-Together), the multiplayer mod for **Kingdom Come: Deliverance II**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod, its helper programs and its setup are published as a pack the launcher installs and updates.
- A bridge program for the launcher: setup checks, saves, logs, and the in-game menu.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Kingdom Come: Deliverance II in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
